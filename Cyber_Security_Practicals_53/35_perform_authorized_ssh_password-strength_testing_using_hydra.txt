PRACTICAL NO. 35
PERFORM AUTHORIZED SSH PASSWORD-STRENGTH TESTING USING HYDRA
==========================================================================================

AIM:
To use THC-Hydra to perform an authorized brute-force/dictionary attack against an SSH service to test password strength.

SYSTEM / SOFTWARE / HARDWARE REQUIREMENTS:
  1. Kali Linux with Hydra installed
  2. Metasploitable 2 (SSH service enabled) as the authorized target
  3. Username and password wordlists

THEORY:
Hydra is a fast, parallelized network login cracker supporting numerous protocols (SSH, FTP, HTTP, etc.). It systematically attempts username/password combinations from provided wordlists against a target service to test for weak credentials, only to be used against systems with explicit authorization.

PROCEDURE:
  1. Confirm SSH (port 22) is open on the target: nmap -p22 <target-IP>.
  2. Prepare/verify a small username list (e.g., msfadmin) and password wordlist (e.g., rockyou.txt or a trimmed sample).
  3. Run Hydra against SSH: hydra -l msfadmin -P /usr/share/wordlists/rockyou.txt ssh://<target-IP>.
  4. Allow Hydra to attempt each password candidate and monitor the output for a 'login successful' result.
  5. Upon success, Hydra displays the valid username/password combination found.
  6. Document the time taken and the specific credentials discovered.
  7. Discuss mitigation: account lockout policies, rate limiting, and key-based SSH authentication.

RESULT:
Hydra successfully identified the weak default SSH credentials (msfadmin/msfadmin) on the Metasploitable 2 target within the authorized test, confirming the service's susceptibility to brute-force attacks.

CONCLUSION:
This exercise demonstrates the real risk posed by default or weak SSH credentials and the effectiveness of rate-limiting, account lockout, and key-based authentication as mitigations.
