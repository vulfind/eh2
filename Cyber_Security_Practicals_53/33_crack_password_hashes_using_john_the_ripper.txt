PRACTICAL NO. 33
CRACK PASSWORD HASHES USING JOHN THE RIPPER
==========================================================================================

AIM:
To use John the Ripper to crack a set of password hashes using dictionary and brute-force attack modes.

SYSTEM / SOFTWARE / HARDWARE REQUIREMENTS:
  1. Kali Linux with John the Ripper installed
  2. Sample password hash file (self-generated, for lab use)
  3. rockyou.txt wordlist

THEORY:
John the Ripper is a widely used open-source password-cracking tool capable of detecting hash types and cracking them using dictionary attacks, brute-force attacks, and rule-based mangling. It supports many hash formats (MD5, SHA1, NTLM, etc.).

PROCEDURE:
  1. Generate a sample hash file for lab use, e.g.: echo 'testuser:$1$abc$examplehash' > hashes.txt (or use /etc/shadow on a disposable lab VM with permission).
  2. Extract the rockyou.txt wordlist if compressed: sudo gzip -d /usr/share/wordlists/rockyou.txt.gz.
  3. Run John in dictionary mode: john --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt.
  4. Monitor cracking progress; John will display cracked passwords as they are found.
  5. View all cracked passwords: john --show hashes.txt.
  6. Optionally attempt incremental (brute-force) mode for short passwords: john --incremental hashes.txt.
  7. Document cracked passwords and time taken for each mode.

RESULT:
John the Ripper successfully cracked the sample password hashes using the rockyou.txt dictionary within a short time, confirming the weakness of the test passwords used.

CONCLUSION:
This exercise demonstrates how quickly weak or common passwords can be cracked using dictionary attacks, reinforcing the importance of strong, unique password policies.
