PRACTICAL NO. 19
ENUMERATE SNMP USING NMAP OR SNMPWALK
==========================================================================================

AIM:
To enumerate Simple Network Management Protocol (SNMP) information on a target host using Nmap NSE scripts and snmpwalk.

SYSTEM / SOFTWARE / HARDWARE REQUIREMENTS:
  1. Kali Linux with Nmap and snmp (snmpwalk) installed
  2. Target host/device with SNMP service enabled (lab-authorized)

THEORY:
SNMP is used to monitor and manage network devices and often uses default or weak 'community strings' (e.g., 'public', 'private') for authentication. A misconfigured SNMP service can leak system information, running processes, network interfaces, and routing tables to an attacker.

PROCEDURE:
  1. Scan for the SNMP port using Nmap: nmap -sU -p 161 <target-IP>.
  2. Run Nmap's SNMP enumeration script: nmap -sU -p 161 --script snmp-info,snmp-sysdescr <target-IP>.
  3. Install snmp tools if required: sudo apt install snmp.
  4. Query system information: snmpwalk -v1 -c public <target-IP> system.
  5. Enumerate running processes: snmpwalk -v1 -c public <target-IP> 1.3.6.1.2.1.25.4.2.1.2.
  6. Enumerate installed software/open ports if accessible via SNMP MIBs.
  7. Document any information disclosed through default community strings.

RESULT:
Using the default 'public' community string, SNMP enumeration successfully disclosed system description, uptime, and process information from the target device.

CONCLUSION:
Weak/default SNMP community strings pose a significant information-disclosure risk; this exercise highlights the importance of changing default community strings and restricting SNMP access.
