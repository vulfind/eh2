PRACTICAL NO. 34
TEST PASSWORD HASHES USING HASHCAT
==========================================================================================

AIM:
To use Hashcat, a GPU-accelerated password recovery tool, to crack password hashes using dictionary attacks.

SYSTEM / SOFTWARE / HARDWARE REQUIREMENTS:
  1. Kali Linux with Hashcat installed
  2. Sample hash file (self-generated, for lab use)
  3. rockyou.txt wordlist

THEORY:
Hashcat is a high-performance password-cracking tool that can leverage GPU acceleration to test large numbers of password candidates per second. It supports a vast range of hash algorithms, each identified by a numeric 'mode' (e.g., -m 0 for MD5, -m 1000 for NTLM).

PROCEDURE:
  1. Generate sample hashes for lab use, e.g.: echo -n 'password123' | md5sum to create an MD5 hash and save it to hash.txt.
  2. Identify the correct hash mode for Hashcat (e.g., -m 0 for MD5).
  3. Run Hashcat in dictionary attack mode: hashcat -m 0 -a 0 hash.txt /usr/share/wordlists/rockyou.txt.
  4. Allow Hashcat to complete the attack and display any cracked hash directly in the terminal.
  5. View previously cracked hashes: hashcat -m 0 hash.txt --show.
  6. Optionally test a rule-based attack for mutated passwords: hashcat -m 0 -a 0 hash.txt /usr/share/wordlists/rockyou.txt -r /usr/share/hashcat/rules/best64.rule.
  7. Document the cracked password and the time taken.

RESULT:
Hashcat successfully cracked the test MD5 hash using the rockyou.txt wordlist in dictionary attack mode, demonstrating fast GPU/CPU-accelerated password recovery.

CONCLUSION:
Hashcat's speed and flexibility make it a powerful tool for password auditing, and the exercise highlights the real-world risk posed by weak password choices against modern cracking hardware.
